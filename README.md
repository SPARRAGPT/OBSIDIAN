# OBSIDIAN — Minecraft Edition

A custom Minecraft utility dashboard built with C++ and Dear ImGui.

## Features
- **Performance monitoring** — live CPU and RAM usage
- **Custom interface** — dark purple theme with animated effects
- **Minecraft tools** — dashboard and utility pages
